# API Documentation Index

Welcome to the API documentation for this modular MVC Express boilerplate.

This documentation provides endpoint details, request/response examples, and authentication/authorization requirements. It is structured by module for easier extension.

## Highlights & Recent Updates

- Enhanced Swagger UI with interactive testing, filters, request duration display, and persisted authorization
- Cloudinary-backed post management with transactional updates and safe asset cleanup
- API log filtering and pagination for error tracking (Super Admin and Cashier access)
- Session tracking with proper client IP detection and two-device login limits
